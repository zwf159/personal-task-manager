# 拾序 Taskflow

一个运行在本机的个人任务管理工具。用项目分组整理任务，为任务设置状态、优先级和截止日期，按条件查找并导出 CSV。中文界面，适配电脑和手机宽度；无需账号、数据库服务或第三方 Python 包。

## 快速开始

需要 Python 3.11 或更新版本。

Windows：双击仓库中的 `start.cmd`，保持启动窗口打开，然后用浏览器访问 **http://127.0.0.1:8765**。

也可以在仓库根目录执行：

```sh
python -m taskflow
```

端口被占用时：

```sh
python -m taskflow --port 8766
```

此时访问 http://127.0.0.1:8766 。按 Ctrl+C 停止服务。

## 使用方式

1. 点击“新建任务”，填写名称，可选备注、项目、日期、优先级和状态。
2. 点击任务标题打开编辑窗口；点击圆形勾选按钮完成或重新打开任务。
3. 点击左侧项目分组旁的加号创建项目，再在任务编辑窗口选择所属项目。
4. 通过“今天到期”“已逾期”、搜索框和状态、优先级筛选定位任务。
5. 点击“导出 CSV”导出当前筛选结果。顶部统计始终显示全部任务的统计。
6. 删除任务前会显示确认。删除项目分组会保留其中的任务，并移至未分组。

首次启动为空白任务列表，不会自动写入示例或假数据。

## 数据与边界

- SQLite 数据文件默认位于仓库中的 `data/taskflow.db`。目录已被 Git 忽略，个人任务不会进入代码提交。
- 可通过 `--database 路径` 指定其他数据文件。
- 备份：先停止服务，再复制数据库文件。恢复：停止服务后，用备份替换该文件。
- CSV 是查看和分析用导出，不是可恢复全部数据的备份；当前没有 CSV 导入。
- 服务仅监听 `127.0.0.1`，未提供多用户登录或联网协作，不适合直接部署到公网。
- 日期为无时区日期；今天和逾期判定使用运行服务的电脑日期。应在运行服务的电脑上使用。
- CSV 使用 UTF-8 BOM，并处理电子表格公式前缀，减少公式执行风险。
- 页面仅加载仓库自身资源，无远程字体、跟踪脚本或 CDN。

## 验证

在仓库根目录运行：

```sh
python -m unittest discover -s tests -v
node --check taskflow/static/app.js
```

Node.js 仅用于可选的 JavaScript 语法检查，运行产品无需 Node.js。测试使用 `data/` 内的临时数据库与临时本机端口，执行后自动清理测试数据库，不影响真实任务。测试运行环境需允许本机 HTTP 连接。

测试覆盖任务完整生命周期、项目删除保留任务、持久化、部分更新、非法输入、逾期与字面量搜索、请求来源检查以及 CSV 中文和公式转义。当前没有浏览器端自动化测试。
