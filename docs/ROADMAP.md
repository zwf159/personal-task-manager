# 后续开发计划

以下是尚未实现的工作，不代表已有功能或历史里程碑。

1. **数据库备份与恢复**：在 `store.py` 使用 SQLite backup 接口创建一致性备份，新增备份列表和恢复前校验，验证损坏文件不会覆盖现有数据。
2. **任务分页**：为 `GET /api/tasks` 增加 limit 和 cursor，避免 `app.js` 一次加载全部任务；验证 1 万条任务下分页无重复、无遗漏。
3. **项目重命名**：增加 `PATCH /api/projects/{id}` 与界面编辑入口，复用名称去空格、长度和重名校验；验证关联任务不丢失。
4. **撤销误删除**：为任务增加 deleted_at 和回收站，替换当前直接删除；验证恢复后项目、备注和日期保持一致。
5. **CSV 导入预览**：新增列映射、日期验证与重复行识别，确认预览后使用事务批量写入；验证任一非法记录不会导致部分导入。
6. **浏览器端回归测试**：覆盖新建、编辑、筛选、项目删除、键盘操作和窄屏布局；加入 HTML 内容注入与错误提示场景。
7. **统一筛选逻辑**：目前界面在 `app.js` 本地筛选，导出在 `store.py` 筛选；统一为服务端查询，并测试大小写、Unicode 和日期边界的一致性。
8. **数据库版本迁移**：在新增字段前加入 PRAGMA user_version 和迁移事务，验证旧版数据库升级失败时可以安全回退。
